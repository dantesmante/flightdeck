# Bundled data

- `vatspy.json.zst`: FIR and sector boundaries, callsign prefixes and
  airports from the [VAT-Spy Data Project](https://github.com/vatsimnetwork/vatspy-data-project)
  (VATSIM), licensed under CC BY-SA 4.0 (`VATSPY-LICENSE.txt`). Converted,
  with coordinates rounded to 0.001 degree, by `tools/build_vatspy.py`; the
  converted file is shared under the same licence.
